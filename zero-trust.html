The seven pillars

What's actually covered today

Microsoft's own Zero Trust Assessment is a PowerShell tool that also reaches into Exchange, SharePoint and Azure Resource Graph — connections a browser page cannot make. Rather than pretend to match it, here is exactly which pillars this tool covers from the browser alone, and which it doesn't yet.

IdentityCovered

Conditional Access gap analysis, phishing-resistant MFA, admin hygiene, consent policy, hybrid identity, device-join restrictions. The deepest area in the tool — 62 checks.

DevicesPartial

Intune compliance policies, enrolment restrictions, encryption and LAPS are checked. Defender for Endpoint device health is not yet reachable from the browser.

SecOpsPartial

Microsoft Secure Score and open Defender alerts are read directly. Deeper Defender XDR configuration (antivirus, vulnerability scanning) needs licensing this tool can't assume.

Applications & privileged accessCovered

PIM activation rules, separation of duties, standing access, tenant-wide consent grants, enterprise app credential and permission review.

DataNot yet

Purview DLP, sensitivity labels and retention policies are configured through Security & Compliance PowerShell, which has no Graph equivalent a browser can call.

NetworkNot yet

Global Secure Access configuration is Graph-reachable in principle but not yet implemented here.

InfrastructureNot yet

Azure Resource Graph and Defender for Cloud recommendations need a separate Azure (ARM) consent and integration — a bigger, separate effort, not a quick addition.

AINot yet

Copilot and AI agent governance checks are the newest part of Microsoft's own framework and aren't implemented here yet either.

Where this comes from

The honest version

This is not a port of Microsoft's tool. Microsoft's Zero Trust Assessment is an open-source PowerShell module that connects to Microsoft Graph, Azure, Exchange Online, Security & Compliance and SharePoint PowerShell, and Azure Resource Graph — six separate connections, several of which simply cannot be made from a browser tab.

What you get here is every check that is reachable with a Microsoft Graph token alone, organised against the same seven pillars Microsoft uses, pulled from the same open control registry — M365-Assess — that powers the rest of this site's assessment. Same promise as everywhere else on this site: your tenant data is read by your browser with your token, and never reaches this website.
