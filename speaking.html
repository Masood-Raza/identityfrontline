Speaking

Talks on Microsoft Entra ID

I speak at user groups, community meetups and conferences about building and running identity on Microsoft Entra ID. Every talk is hands-on and based on a lab you can rebuild yourself afterwards.

Talk topics

Build a free Microsoft Entra ID and Active Directory homelab

Hands-on lab · Beginner to intermediate · 30–60 min

Stand up Active Directory, sync it to Microsoft Entra ID with Entra Connect, and turn on MFA and self-service password reset, all on free tiers. Attendees leave with a lab they can keep building on and a portfolio checklist.

Related guide →

Conditional Access that doesn't lock you out

Talk or demo · Intermediate · 30–45 min

A practical baseline for Conditional Access: break-glass accounts, report-only rollout, MFA and device policies, and how to read sign-in logs to see what a policy actually did before you enforce it.

Related guide →

Entra ID as the identity provider for AWS: SAML SSO and SCIM

Live demo · Intermediate · 45 min

Connect Microsoft Entra ID to AWS IAM Identity Center with SAML single sign-on, then automate user and group provisioning with SCIM. Covers the provisioning cycle, provision on demand, and the mistakes that break sign-in.

Related guide →

Automating the leaver: session revocation with Microsoft Graph

Demo · Intermediate to advanced · 45 min

Offboarding that actually ends access: disable in AD, sync, revoke Entra sessions with Microsoft Graph, cascade SCIM deprovisioning to downstream apps, handle the mailbox, and prove it in the audit logs.

Related guide →
